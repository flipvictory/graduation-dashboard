전체 데이터 백업

현재 브라우저에 저장된 학점 계산기 과목정보, 졸업 인증 요건 설정, 등록된 모든 할 일, 과목별 공부시간 기록 전체를 하나의 텍스트(.txt) 파일로 결합하여 PC나 스마트폰에 안전하게 내려받습니다.

전체 데이터 복구

이전에 보관해둔 텍스트 백업 파일을 업로드하여, 기기 변경이나 데이터 유실 시 모든 기록을 한 번에 원상복구합니다. 복구 진행 시 기존 데이터는 백업 데이터로 완전 교체됩니다.

전체 데이터 초기화

주의: 실행 시 저장된 모든 기록(학점, 할일, 타이머 등)이 브라우저 캐시에서 영구적으로 삭제되며 완전히 빈 초기 상태로 되돌아갑니다.
